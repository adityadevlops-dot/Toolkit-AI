# 🤖 Multi-Tool LLM Agent

An intelligent AI assistant powered by multiple tools, built with Python and Streamlit.

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![Streamlit](https://img.shields.io/badge/Streamlit-1.28+-red.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## 🎯 Features

- **🧮 Calculator**: Advanced math including derivatives, integrals, and equation solving
- **🔍 Web Search**: Real-time web search capabilities
- **🌤️ Weather**: Current weather for any location worldwide
- **📚 Wikipedia**: Instant access to Wikipedia knowledge
- **📄 File Reader**: Support for PDF, DOCX, TXT, CSV, JSON files
- **🌐 URL Reader**: Extract content from any web page
- **💻 Code Executor**: Safely run Python code snippets
